# Public repo, Exact Locations kept outside it

The repo is public so it can be shown in job applications, which means anything committed is published. Exact Locations, and the real Place of Sensitive Sightings, therefore never enter the repo: the CLI writes only Published Locations into committed data and keeps the exact values in a git-ignored private file that is backed up separately. Do not "simplify" by moving exact coordinates into the content files.
